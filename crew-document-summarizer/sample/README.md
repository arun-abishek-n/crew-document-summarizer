# Sample Documents

This folder is just a convenient place to drop test PDFs while you try out
the app locally — it is not read by the code automatically.

To test the app:

1. Put any PDF file here (a short report, an article, a resume, etc.).
2. Run the app with `streamlit run app.py`.
3. Upload the file from this folder using the "Upload a PDF document" button.

Suggestions for good test files:
- A short 1-2 page article or blog post exported as PDF.
- A longer document (10+ pages) to see the chunking logic in action.
- An empty or scanned/image-only PDF to see the friendly error handling.

See the "Testing the Application" section in the main [README.md](../README.md)
for the full list of test cases and expected results.
